# RoadLink — SIH 2026

RoadLink is a traffic intelligence and road monitoring platform built for the Smart India Hackathon.

## Core Pipeline

Road Video
→ Vehicle Detection
→ Persistent Vehicle Tracking
→ Speed Analysis
→ Traffic Analysis
→ ANPR / OCR
→ Road Intelligence
→ Alerts / Journeys / Emergency Response

## Development Status

Phase 1 — Vehicle detection + persistent tracking

Phase 2 — Speed estimation

Phase 3 — Traffic density and congestion

Phase 4 — Traffic alerts

Phase 5 — Vehicle journey reconstruction

Phase 6 — Emergency corridor recommendation

Phase 7 — ANPR / watchlist / cloned-plate integration

Phase 8 — RoadLink control-room frontend

## Important

The prototype uses recorded road video as input.

Live CCTV integration will only be claimed when an actual live camera source is connected.
